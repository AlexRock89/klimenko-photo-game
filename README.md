# Обычный день фотографа

Браузерная пиксельная игра про Оксану Клименко, парк и три минуты на лучшие кадры. Бегай по парку, лови удачные моменты, наводи фокус, собирай бонусы и не давай помехам испортить снимок. К финалу наступает вечер: темнеют аллеи, загораются фонари, а у Оксаны в одной руке камера, в другой фонарик.

Игра работает как обычный статический сайт: чистый JavaScript и Canvas, без библиотек, сборки и внешних запросов. Звуки лежат внутри `sounds-data.js`.

## Запустить на компьютере

Просто открой `index.html` двойным кликом, отдельный сервер не нужен. Звук включается после первого действия игрока.

Если хочешь запустить через локальный сервер, открой терминал в папке проекта:

```sh
python -m http.server 8000
```

На macOS и Linux команда может называться `python3`. Потом открой в браузере **http://127.0.0.1:8000**.

## Опубликовать на GitHub Pages

1. Загрузи все файлы проекта в корень репозитория, ветка `main`. ZIP загружать не нужно: GitHub не распаковывает его.
2. Открой **Settings → Pages**.
3. В блоке **Build and deployment** выбери **Source: Deploy from a branch**, ветку **main**, папку **/ (root)** и нажми **Save**.
4. Через минуту-две игра откроется по адресу `https://ИМЯ.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/`.

Если после обновления файлов слышишь или видишь старую версию, обнови страницу с очисткой кеша: **Ctrl+Shift+R** (на Mac **Cmd+Shift+R**).

## Управление

- **WASD / стрелки** — бегать по парку.
- **Мышь** — наводить рамку.
- **ЛКМ** — сделать снимок со вспышкой.
- **Удерживать ПКМ** — навести фокус: кадр получается чётче и приносит больше очков.
- **Пробел** — пауза и правила игры; **Enter** — начать или повторить съемку.
- **M / N** — включить или выключить звук / музыку.
- **На телефоне**: касание начинает съемку, управление сенсорное.

## Как играть

- Съемка длится 3 минуты и делится на 5 этапов. Чем дальше, тем больше в парке происходит.
- Очки зависят от того, кто попал в рамку, насколько он в центре, есть ли фокус и что ещё влезло в кадр. Серии удачных снимков дают множитель.
- В парке гуляют клиенты: клоун, модница, хипстер, бариста, дедушка, семья, пара, свадьба, бегун, уличный музыкант. После вспышки каждый по-своему реагирует звуком.
- Бонусы: кофе, линза, вспышка, часы, звезда. Они лежат 14 секунд, за пределами экрана их показывает стрелка.
- Помехи: голуби, кот, мартышка, собака, турист с селфи. Табор приходит при наборе очков: толпа в кадре портит снимок, а дети-воришки тащат бонусы.
- Погода меняется каждые 35–50 секунд: ясно, ветер, дождь, снег. Она влияет на скорость бега и на скорость фокуса.
- Под конец наступает вечер.
- Есть 10 достижений. Рекорд и достижения хранятся в браузере для каждого адреса сайта отдельно.
- Пасхалки прячутся в парке. Ищи динозавра и утку в фонтане.

## Структура

| Файл | Что внутри |
| --- | --- |
| `index.html` | Страница и подключение скриптов |
| `game.js` | Основной цикл, съемка, подсчёт очков, интерфейс, вечер |
| `systems.js` | Этапы, расписание, погода, достижения, табор |
| `actors.js` | Клиенты, животные, турист, табор |
| `art-people.js`, `art-world.js` | Отрисовка людей, парка и объектов в пикселях |
| `sound.js`, `sounds-data.js` | Звуки, музыка, реакции на вспышку |
| `touch.js` | Управление на телефоне |
| `CREDITS-ЗВУКИ.txt` | Источники и лицензии записей |

## Звуки и лицензии

Большая часть записей свободная (CC0), но часть взята из подборок с другими условиями: ESC-50 (CC BY-NC) и записи без явной лицензии. Поэтому игра сейчас подходит только для личного некоммерческого использования. Подробные источники в [CREDITS-ЗВУКИ.txt](CREDITS-ЗВУКИ.txt). Если игра станет коммерческой, эти записи нужно заменить.

Лицензия на основной авторский код проекта не выбрана.
